# Mi configuración de Vim

Configuración personalizada de Vim 9 con tema Catppuccin Mocha,
dashboard de inicio, ejecutor de código (F5), barra de desplazamiento
con mouse y atajos estilo editor normal.

## Instalación

    git clone https://github.com/TU_USUARIO/dotfiles.git ~/dotfiles
    ln -s ~/dotfiles/vimrc ~/.vimrc
    curl -fLo ~/.vim/autoload/plug.vim --create-dirs \
        https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim

Abre Vim y ejecuta `:PlugInstall`.
